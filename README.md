# IrisBot 🤖

IrisBot is a multi-purpose Discord bot built with Python and discord.py.

## ✨ Features

- 🎵 Music system
- 🛡️ Moderation
- 🎫 Ticket system
- 👋 Welcome system
- 📝 Logging
- 🧰 Utility commands
- 🗄️ MongoDB database
- ⚡ Slash commands
- 🎧 Lavalink music backend

## 🛠️ Requirements

- Python 3.10+
- Java 21+
- Lavalink
- MongoDB
- A Discord Bot application
